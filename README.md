# PoS-duka
​A Python-based Point of Sale (POS) application designed to simplify store management, track sales, and manage inventory efficiently.
​Key Features
​Sales Tracking: Easily record daily sales and transactions.
​Inventory Management: Keep track of stock levels in real-time.
​Database Integration: Reliable SQL database for storing sales and product data.
​User-Friendly: Simple interface for quick operations.
